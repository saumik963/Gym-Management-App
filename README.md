## About

Fitness Care Gym is a lightweight, **100% offline** web application for managing gym members and their fees. It's built to run entirely client-side (no backend/server dependency required for core use), making it well suited for small gyms or trainers who want a simple digital record-keeping tool without needing constant internet access.
